## What I'm about

I'm a Computer Science honors student at Texas State University with a minor in Data Analytics and a 4.0 GPA. I like understanding how things work under the hood, so I build them from scratch: neural networks in plain NumPy, backpropagation by hand, and higher-order automatic differentiation in PyTorch.

## Featured work

- **ML Algorithms from Scratch** - a neural network, linear and logistic regression, and decision trees built with only NumPy (no scikit-learn), with forward propagation, backpropagation and gradient descent written by hand.
- **Higher-Order Automatic Differentiation** - derivatives of a Gaussian to arbitrary order with PyTorch autograd, benchmarked across CPU and GPU to study how cost scales with derivative order.
- **Neural Network Function Approximation** - controlled experiments on shallow vs. deep ReLU networks, comparing activations, losses, and width vs. depth against approximation error.
- **Large-Scale Data Pipeline** - 5M+ records processed and validated in BigQuery with strict schema checks, plus Looker Studio dashboards for technical and non-technical audiences.
